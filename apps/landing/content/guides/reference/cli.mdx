# Aomi client CLI

The `aomi` executable ships with [`@aomi-labs/client`](https://www.npmjs.com/package/@aomi-labs/client). It calls a running Aomi environment. It is separate from the Rust `aomi-build` toolchain used to author plugins and ship Apps.

## Install

```bash
npm install -g @aomi-labs/client@latest
aomi --version
aomi --help
```

Or run one command without a global install:

```bash
npx @aomi-labs/client@latest --help
```

On September 22, 2026, npm `latest` is `0.7.6`. Merged frontend source is `0.9.4`, but source-only account App installation and persistent credential commands require a matching package release and backend deployment.

## Common commands

```bash
# Agent chat uses Auto routing unless you select an App.
aomi chat "what is the price of ETH?" --new-session
aomi chat "quote a swap" --mode direct --app zerox

# Session and model controls.
aomi session list
aomi session status
aomi session interrupt
aomi model list

# Review a durable Agent Action.
aomi tx list
aomi tx simulate <action-id>
aomi tx export <action-id>
aomi tx sign <action-id>

# Discover and call Pipeline directly.
aomi pipeline apps
aomi pipeline operations --app aave
aomi pipeline operation supply --app aave

# Authenticate account-owned work.
aomi account login
aomi account whoami
```

The `tx` group operates on Agent Actions. `tx simulate` accepts EVM execution Actions. `tx sign` executes the exact prepared Action with the configured wallet. `--aa` and `--eoa` only assert whether a pending Action is a backend-prepared ERC-4337 owner authorization; they do not choose an AA provider.

## Credentials

These stores serve different purposes:

- `aomi account login` manages account identity and exact-resource OAuth grants.
- `--api-key` or `AOMI_API_KEY` supplies an App access key.
- `aomi secret add NAME=value` creates temporary session secret handles.
- `--provider-key` and the REPL `/key` command manage model-provider BYOK.
- Client `0.9.4` source adds `aomi app credentials status|set|replace|remove` for persistent per-user App slots. Values come from a hidden prompt or stdin, never a command-line argument.

There is no top-level `--secret` or `aomi sign` command. Use `aomi tx list` rather than treating the `aomi tx` command group as a listing shortcut. The CLI also rejects `--aa-provider` and `--aa-mode`.
