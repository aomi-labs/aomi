# Aomi client CLI

Install the npm client and inspect the command surface in your installed version:

```bash
npm install -g @aomi-labs/client@latest
aomi --version
aomi --help
```

Start an Agent turn, then inspect any wallet Action it creates:

```bash
aomi chat "swap 1 ETH for USDC" \
  --new-session \
  --public-key 0xYourAddress \
  --chain 1
aomi tx list
aomi tx simulate <action-id>
aomi tx sign <action-id>
```

The CLI keeps the active session, routing target, account grants, and optional wallet configuration under `AOMI_STATE_DIR` or `~/.aomi`. Pending Actions remain in the backend Agent session and are fetched by `aomi tx list`.

Use Pipeline when you already know the App operation:

```bash
aomi pipeline apps
aomi pipeline operations --app aave
aomi pipeline operation supply --app aave
aomi pipeline build supply \
  --app aave \
  --arguments '{"asset":"USDC","amount":"100"}'
```

The current signing contract is prepared by the backend. `--aa` requires a backend-prepared ERC-4337 owner-authorization Action, and `--eoa` rejects that Action kind. The CLI rejects `--aa-provider` and `--aa-mode`.
