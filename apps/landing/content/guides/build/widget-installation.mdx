---
title: Widget installation
description: Install the packaged widget and choose its authentication mode.
---

Use `@aomi-labs/widget` to embed the complete widget:

```bash
npm install @aomi-labs/widget
```

Follow the [quickstart](/docs/build/quickstart) for a browser-wallet example, or the [canonical installation guide](https://aomi.dev/docs/guides/widget/installation) for Para and Privy. The widget requires an explicit `auth` configuration, API origin, and deployed Application ID. A connected wallet still needs user approval before signing.

Existing registry JSON remains frozen during the announced retention window. New integrations use npm.
