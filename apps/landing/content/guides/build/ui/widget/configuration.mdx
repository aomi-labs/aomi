---
title: Widget configuration
description: Configure the widget with explicit props and optional wallets.
---

Use the [canonical customization guide](https://aomi.dev/docs/guides/widget/customization)
for dimensions, themes, routing and controlled thread selection.

The default API is `https://chat.aomi.dev`, and browser-wallet auth is the default.
`applicationId` identifies your hosted App independently of the `routing` target.
Pass provider identifiers explicitly through the optional lazy Para or Privy factory.
The package does not read environment variables or provision backend AA wallets
for embeds.
