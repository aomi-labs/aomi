---
title: AomiFrame
description: Compose the compiled widget shell inside a first-party host.
---

Use `AomiWidget` for an ordinary embed. A host that supplies its own chrome can
compose the same interface through the compiled frame entry:

```tsx
"use client";
import { AomiFrame } from "@aomi-labs/widget/frame";
import "@aomi-labs/widget/styles.css";

export default function Assistant() {
  return (
    <AomiFrame.Root backendUrl="https://chat.aomi.dev" applicationId="123">
      <AomiFrame.Header />
      <AomiFrame.Composer />
    </AomiFrame.Root>
  );
}
```

Pass `backendUrl` explicitly, or `""` for a same-origin API. The frame does not
read environment variables. Public wallet-provider inputs and account management
transport are host configuration. Pass `products` explicitly to enable a product
switcher; ordinary embeds omit it.

See [customization](https://aomi.dev/docs/guides/widget/customization) for layout,
themes, routing and controlled thread selection.
