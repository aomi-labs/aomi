---
title: "Widget components"
description: "Install and configure the compiled Aomi widget."
---

Install the compiled widget from npm:

```bash
npm install @aomi-labs/widget
```

```tsx
"use client";
import { AomiWidget } from "@aomi-labs/widget";
import "@aomi-labs/widget/styles.css";
export default function Assistant() { return <AomiWidget applicationId="123" />; }
```

The widget includes its styles and browser-wallet integration. Set only your
hosted Application ID for the default configuration. Add an explicit lazy Para
or Privy entry only when your product uses that provider.

The canonical [widget quickstart](https://aomi.dev/docs/guides/widget/quickstart),
[wallet installation](https://aomi.dev/docs/guides/widget/installation) and
[customization guide](https://aomi.dev/docs/guides/widget/customization) cover
origin registration, optional wallets, layout and routing.

Existing registry JSON remains frozen during the announced retention window.
New integrations use npm rather than copied component source.
