---
title: Widget quickstart
description: Install the widget with one required prop.
---

```bash
npm install @aomi-labs/widget
```

```tsx
"use client";
import { AomiWidget } from "@aomi-labs/widget";
import "@aomi-labs/widget/styles.css";
export default function Assistant() { return <AomiWidget applicationId="123" />; }
```

See the [canonical quickstart](https://aomi.dev/docs/guides/widget/quickstart)
for origin registration and optional wallet providers.
