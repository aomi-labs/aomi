Use `@aomi-labs/widget` when you want a complete interface with conversations, wallet authentication, and transaction review. Use `@aomi-labs/react`, the headless library, when you want to compose your own UI and wallet provider tree.

| Surface           | Your application supplies                                                                          |
| ----------------- | -------------------------------------------------------------------------------------------------- |
| Packaged widget   | Deployed Application ID; optional API origin and wallet-provider configuration |
| Headless library  | Runtime provider, UI components, caller authentication, and wallet capabilities                    |
| TypeScript client | Agent or Pipeline flows, host UI, and explicit wallet review                                       |

## Embed the widget

```bash
npm install @aomi-labs/widget
```

```tsx
"use client";

import { AomiWidget } from "@aomi-labs/widget";
import "@aomi-labs/widget/styles.css";

export default function AssistantPage() {
  return (
    <AomiWidget applicationId="123" height="100dvh" />
  );
}
```

Use the production API origin `https://chat.aomi.dev` or the compatible origin supplied for your environment. The Application ID selects an activated App; it is not an API key. The widget creates an origin-bound session and keeps transaction review in the user interface.
