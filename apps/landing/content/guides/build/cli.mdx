# Client CLI

The npm `aomi` command talks to a running Aomi environment. Use it after your App is available in that environment to inspect discovery, run a Direct Agent turn, or call Pipeline operations.

```bash
npm install -g @aomi-labs/client@latest
aomi --version

aomi pipeline app my-app
aomi pipeline operations --app my-app
aomi chat "exercise the new tool" --mode direct --app my-app --new-session
```

Use the Rust `aomi-build` toolchain to scaffold, compile, and ship the plugin itself. The npm client does not replace the builder workflow.

For the complete client surface, see the canonical [Client CLI reference](https://aomi.dev/docs/reference/client-cli). For authoring commands, see the [builder toolchain](https://aomi.dev/docs/build/toolchain/aomi-build).
