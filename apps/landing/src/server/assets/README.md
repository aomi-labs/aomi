# OpenGraph assets

These unmodified fonts are the exact Google Fonts responses previously fetched
by Landing's `/api/og` handler. They are now bundled with the server so rendering
needs no external network. The existing background remains
`public/og-bg.jpg` and is imported as an inline data URI.
