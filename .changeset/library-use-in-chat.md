Library rows and details offer "Use in chat", which tags the package in the composer, and "Turn on" or "Connect" in place. "Add with code" turns the package on, and a package added with a code can be removed. A change shows in "@" of every chat without a reload. The Wallet section says what is checked, in total, and nothing for a package that declares nothing. Sheets and confirms close when the account changes, and no Library change is sent for another account. A signature refused because an earlier review is waiting links to it.
