# @aomi-labs/skills

Official Aomi skills meta-package. This package reserves the npm name and points to the canonical skills repository.

- Canonical repo: https://github.com/aomi-labs/skills
- Install skills into your agent host:

```bash
npx skills add @aomi-labs/skills
```

Notes:

- This stub contains no install scripts and no code. The canonical skills live in the repository above.
- Maintainers: publish with:

```bash
cd npm-packages/aomi-labs-skills
npm publish --access public
```
