# 2026-09-20

- Replaced the widget's parallel wallet row derivations with the composer-owned
  account-aware wallet state. `identity.address` and `identity.svmAddress` now
  publish only the selected linked and locally signable wallet.
- Added per-account, per-family operating-wallet selection storage. Temporary
  provider unavailability retains the selection; unlinking clears it; merely
  connecting another wallet does not take over.
- Embedded wallet mismatches fail closed and no longer expose challenge Link.
  Settings explains mismatch/loading/provider-unavailable states, and Privy
  automatic-signing setup is offered only for an operating Privy EVM wallet.
- Removed `mergeWalletRows`, `buildUnifiedAccountWallets`, Settings identity
  fallbacks, connected-summary derivation, and the signing-policy fallback that
  could select a non-operating signer.
- Bumped `@aomi-labs/widget-lib` to 3.0.0 because the public identity and row
  contracts intentionally changed.
